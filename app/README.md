# 망각곡선 복습

에빙하우스 망각곡선 기반 간격 반복 암기 카드 앱 (Anki 스타일). 서버·빌드 없이 동작하는 PWA입니다.

## 기능
- 덱/카드 관리, 여러 장 붙여넣기 추가 (`앞면 ; 뒷면`)
- 복습: 정답 보기 → 다시 / 어려움 / 좋음 / 쉬움 (버튼에 다음 간격 표시), 실행 취소(↩︎), 단축키(Space, 1–4, Z)
- 간격: 1일 → 2일 → 4일 → 7일 → 15일 → 30일 → 60일 → 이후 2배. 하루의 시작은 새벽 4시.
- 통계: 오늘 복습, 연속 학습일, 30일 유지율, 앞으로 7일 예정, 12주 히트맵
- JSON 내보내기/가져오기, 다크 모드, 오프라인 동작

## 아이폰에 설치
1. 이 `app/` 폴더를 HTTPS로 호스팅합니다 (예: GitHub Pages — 저장소 Settings → Pages → 브랜치/`/app` 폴더 선택).
2. 아이폰 **사파리**로 주소를 엽니다.
3. 공유 버튼 → **홈 화면에 추가**.
4. 홈 화면의 아이콘으로 실행하세요. 홈 화면 앱은 저장 데이터를 iOS가 임의로 지우지 않습니다.

데이터는 기기 브라우저(IndexedDB)에만 저장되므로 설정 → 내보내기로 정기 백업하세요.

## 로컬 실행 / 테스트
```
cd app && python3 -m http.server 8000   # http://localhost:8000
node --test                              # scheduler / stats 단위 테스트
```
파일을 수정하면 `sw.js`의 `VERSION`을 올려야 설치된 앱이 새 파일을 받습니다.
