# 에빙하우스 복습 카드 앱 — 설계

## 목표
Anki처럼 카드를 만들고 매일 복습하는 개인용 웹앱. 에빙하우스 망각곡선 기반 간격 반복으로 복습 일정을 자동 계산한다. 아이폰 사파리에서 "홈 화면에 추가"하여 앱처럼 사용(PWA), 오프라인 동작.

## 비목표 (1차)
계정/클라우드 동기화, 푸시 알림, 이미지·음성 카드, 서버.

## 기술
빌드 없는 순수 HTML/CSS/ES modules, 저장은 IndexedDB. 정적 호스팅(GitHub Pages)으로 배포 가능. 위치: `app/`.

## 화면
1. **홈(덱 목록)**: 덱별 새 카드/복습 수, 덱 탭 → 복습 시작. 덱 추가, 통계, 설정 진입.
2. **복습**: 앞면 → 정답 보기(뒤집기 애니메이션) → 다시/어려움/좋음/쉬움 (버튼에 다음 간격 표시). 남은 수 표시, 실행 취소, 단축키(Space, 1–4, Z).
3. **카드 관리**: 덱 내 카드 목록, 검색, 추가/수정/삭제, 여러 장 붙여넣기 추가(한 줄에 `앞면<TAB 또는 ;>뒷면`).
4. **통계**: 오늘 복습 수, 연속 학습일, 최근 12주 히트맵, 앞으로 7일 복습 예정, 기억 유지율.
5. **설정**: 하루 새 카드 수(기본 20), JSON 내보내기/가져오기, 전체 초기화.

## 스케줄러 (`scheduler.js`, 순수 함수)
- 간격 단계(일): `[1, 2, 4, 7, 15, 30, 60]`, 마지막 이후 복습마다 ×2.
- 카드: `{stage, due(day number), reps, lapses}`; 새 카드는 `stage = -1`.
- 평가: **다시** → stage 0, 같은 세션 10분 뒤 재출제, lapses+1 / **어려움** → 현재 간격 유지(새 카드는 stage 0) / **좋음** → stage+1 / **쉬움** → stage+2.
- 하루의 시작은 새벽 4시. 날짜는 `dayNumber(ts)`로 정수화.
- 간격 표시 라벨(`10분`, `1일`, `2주`, `1개월`…) 제공.

## 데이터 (IndexedDB `reviewer`)
- `decks`: `{id, name, createdAt}`
- `cards`: `{id, deckId, front, back, stage, due, reps, lapses, createdAt}` (인덱스: deckId, due)
- `logs`: `{id, cardId, deckId, ts, rating, prevState}` (통계와 실행 취소용)
- `meta`: `{key, value}` (설정)

## 오류 처리
저장 실패 시 토스트로 알림. 가져오기 JSON 검증 실패 시 기존 데이터 유지. IndexedDB 불가 시 안내 화면.

## 테스트
- Node 내장 테스트러너로 `scheduler.js`(단계 이동, 간격, 4시 경계, 다시 처리, 라벨) 단위 테스트.
- 브라우저(Playwright)로 아이폰 크기에서 덱 생성→카드 추가→복습→통계→내보내기/가져오기 흐름 확인.
